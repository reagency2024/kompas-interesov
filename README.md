# КОМПАС ИНТЕРЕСОВ

Мини‑приложение для профориентации подростка по методике **O*NET Interest Profiler**.

- **Приложение онлайн:** https://claude.ai/artifact/79omsdby4SQHVn3eNwdSCC (по умолчанию ссылка приватная; чтобы открыть её другому человеку, включите доступ через меню «Поделиться»).
- **Локально:** откройте `index.html` в браузере. Файл самодостаточный, сервер не нужен.

## Методика

O*NET Interest Profiler разработан при поддержке Министерства труда США (National Center for O*NET Development) на основе теории профессиональных типов Джона Холланда (RIASEC). Используется сокращённая форма из **60 вопросов**: по 10 видов деятельности на каждый тип. Вопросы идут вперемешку в порядке R‑I‑A‑S‑E‑C, как в оригинале.

| Код | Тип | В приложении | Суть |
|---|---|---|---|
| R | Realistic, реалистичный | Практик | руки, техника, инструменты, природа |
| I | Investigative, исследовательский | Мыслитель | наука, анализ, эксперименты |
| A | Artistic, артистический | Творец | творчество, самовыражение |
| S | Social, социальный | Помощник | учить, помогать, заботиться |
| E | Enterprising, предприимчивый | Лидер | руководить, убеждать, бизнес |
| C | Conventional, конвенциональный | Организатор | порядок, данные, точность |

Формулировки вопросов переведены и адаптированы на русский язык. Официального русского перевода и российских норм у этой версии нет, поэтому результат служит ориентиром для разговора, а не диагнозом. Тест измеряет интересы, а не способности.

## Как считаются баллы

- Шкала ответа из 5 вариантов: «очень не понравилось бы» = 0, «не понравилось бы» = 1, «не знаю» = 2, «понравилось бы» = 3, «очень понравилось бы» = 4.
- Баллы по каждому типу суммируются по 10 вопросам: от **0 до 40** (как на сайте My Next Move).
- **Код Холланда**: три типа с наибольшими баллами, по убыванию (например, `ASI`). При равенстве баллов порядок берётся R‑I‑A‑S‑E‑C.
- Профиль рисуется на шестиугольнике Холланда: соседние типы похожи, противоположные сильнее всего различаются.
- Дополнительные пометки в результате:
  - максимальный балл ≤ 12: интересы пока не определились, тест стоит повторить через полгода–год;
  - разница между максимумом и минимумом ≤ 6: ровный профиль, широкий выбор;
  - первый тип опережает второй на 8 и более баллов: ярко выраженный ведущий интерес.

## Что показывает результат

- код Холланда и шестиугольник профиля с баллами;
- для трёх ведущих типов: описание, примеры профессий, школьные предметы, где попробовать себя;
- профессии на стыке двух самых сильных интересов;
- советы родителям и кнопка «Скопировать результат».

Ответы сохраняются в браузере, тест можно прервать и продолжить. Внутри Telegram (если подключить скрипт `telegram-web-app.js`) окно разворачивается на весь экран и даёт тактильный отклик при ответах.
