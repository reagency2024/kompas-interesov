# КОМПАС ИНТЕРЕСОВ

Мини‑приложение для профориентации выпускника: 10 тестов в одном месте.

- **Приложение онлайн:** https://claude.ai/artifact/79omsdby4SQHVn3eNwdSCC (ссылка приватная; чтобы открыть её другому человеку, включите доступ через меню «Поделиться»).
- **Локально:** откройте `index.html` в браузере. Файл самодостаточный, сервер не нужен.

Каждый тест проходится отдельно, в любом порядке. Ответы сохраняются в браузере, тест можно прервать и продолжить. На главном экране собирается сводка по пройденным тестам, её можно скопировать целиком.

## Почему «открытые аналоги»

Большинство известных методик (Strong, Morrisby, CliftonStrengths, Hogan, MBTI, Birkman, DAT, CDSE, SHL OPQ32) платные и защищены авторским правом: их вопросы и ключи не опубликованы. Поэтому в приложении два вида тестов:

- **Оригинальная методика** — опубликованные вопросы, свободные для использования, в переводе на русский: O*NET Interest Profiler, IPIP Big Five, CAAS.
- **Открытый аналог** — тест по той же научной модели, но с вопросами, составленными для приложения. Измеряет то же самое, но без норм оригинала.

У переводов и аналогов нет российских норм для подростков, поэтому результаты служат ориентиром для разговора, а не диагнозом.

## Как считаются баллы

Ответы хранятся как 0–4 (пять вариантов ответа).

- **RIASEC (O*NET):** «очень не понравилось бы» = 0 … «очень понравилось бы» = 4. По каждому из шести типов 10 вопросов → **0–40**. Код Холланда — три типа с наибольшими баллами (при равенстве порядок R‑I‑A‑S‑E‑C). Пометки: максимум ≤ 12 — интересы не определились; разброс ≤ 6 — ровный профиль; отрыв первого типа от второго ≥ 8 — ярко выраженный интерес.
- **Большая пятёрка:** 1–5 баллов, обратные вопросы считаются как 6 − ответ (ключи по листу IPIP‑50). По каждой черте **10–50**: ниже 26 — низкий, 26–36 — средний, выше 36 — высокий уровень.
- **Сильные стороны:** 3 вопроса × 1–5 → **3–15** на каждую из 24; топ‑5 — «подписные» сильные стороны. Шесть групп достоинств — среднее по их сильным сторонам.
- **Психологический тип:** 8 пар утверждений на шкалу, ответ 0 («точно А») … 4 («точно Б») → **0–32**, середина 16. Меньше 16 — первая буква (E, S, T, J), 16 и больше — вторая (I, N, F, P). Выраженность = |сумма − 16| / 16: до 20% слабая, до 50% умеренная, выше — ясная.
- **Поведение под стрессом:** 3 вопроса × 1–5 → **3–15** на каждую из 11 моделей: 12+ проявляется заметно, 9–11 умеренно.
- **Якоря карьеры:** 4 вопроса × 1–5 → **4–20** на каждый из 8 якорей; главный — с наибольшим баллом.
- **Рабочая среда:** 3 пары × 0–4 → **0–12** на шкалу, середина 6: ≤ 3 или ≥ 9 — явное предпочтение, 4–5 или 7–8 — «скорее», 6 — без предпочтения.
- **Способности:** доля верных ответов по каждому субтесту: ≥ 75% — высокий, 50–74% — средний. Таймера и норм нет; после теста показывается разбор ошибок.
- **Карьерная адаптивность (CAAS):** 6 вопросов × 1–5 на каждую из 4 шкал (забота о будущем, контроль, любознательность, уверенность), всего **24–120**. Средний балл шкалы ниже 3,5 — зона развития.
- **Уверенность в выборе:** 5 вопросов × 1–5 на каждую из 5 шкал (самопознание, информация, выбор цели, планирование, решение проблем), всего **25–125**. Среднее ≥ 4 — высокая, 3–4 — средняя уверенность.
